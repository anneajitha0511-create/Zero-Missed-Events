CampusPulse - prototype

Run: unzip, then double click index.html (Chrome / Edge / Firefox). No installation.

Files:
  index.html  - 3 pages (Find events, My tickets, Post an event)
  style.css   - design
  script.js   - logic (radar, live countdown, picks, filters, save, form checks, demo verify)

Events in script.js are SAMPLE data. Edit the "events" list to add real ones.
